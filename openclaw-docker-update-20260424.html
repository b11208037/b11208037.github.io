⚠️ OpenClaw Docker 部署：過期資訊修正對照表

資料來源：ohya.co 原文（2 個月前） vs. 官方 docs.openclaw.ai（2026-04 最新）

⚡ 需要修改

1. 自動化腳本路徑已變更

原文（過期）
./docker-setup.sh
現在是
./scripts/docker/setup.sh

腳本位置從 repo 根目錄改到了 scripts/docker/ 子目錄。記得先進入 repo 再執行。

⚡ 需要修改

2. Node.js 版本更新（22 → 24）

原文（過期）

需要 Node.js 22 以上版本

Docker 映像基於 node:22-bookworm

現在是

映像基於 node:24-bookworm

✅ 已過時

3. 官方 Docker 映像已存在！

原文說「官方不提供預建的 Docker image，Docker Hub 上沒有 openclaw/openclaw:latest」，這個資訊已經過時了。

現在有官方預建映像，可以直接使用 ghcr.io/openclaw/openclaw:latest，不需要自己 build。

# 使用預建映像（推薦）
export OPENCLAW_IMAGE="ghcr.io/openclaw/openclaw:latest"
./scripts/docker/setup.sh

常見標籤：main、latest、2026.2.26 等版本號

📝 補充

4. 新增環境變數

相較原文，官方文件多了以下變數：

環境變數 用途
OPENCLAW_IMAGE使用遠端預建映像（不用本地 build）
OPENCLAW_EXTENSIONS建構時預先安裝插件依賴
OPENCLAW_SANDBOX啟用 Agent 沙箱（值：1, true, yes, on）
OPENCLAW_DOCKER_SOCKET覆寫 Docker socket 路徑（rootless Docker 用）
OPENCLAW_GATEWAY_BIND設定绑定模式（lan / loopback / tailnet / auto）
🆕 新功能

5. ClawDock - Docker 管理輔助工具（新！）

官方現在有提供方便的 Shell 輔助工具：

mkdir -p ~/.clawdock
curl -sL https://raw.githubusercontent.com/openclaw/openclaw/main/scripts/clawdock/clawdock-helpers.sh \
  -o ~/.clawdock/clawdock-helpers.sh
echo 'source ~/.clawdock/clawdock-helpers.sh' >> ~/.zshrc
source ~/.zshrc

之後可用 clawdock-start、clawdock-stop、clawdock-dashboard 等指令管理 Docker。

📝 補充

6. 新增健康檢查端點

# 存活探針
curl -fsS http://127.0.0.1:18789/healthz

# 就緒探針
curl -fsS http://127.0.0.1:18789/readyz

# 詳細健康報告（需 Token）
docker compose exec openclaw-gateway node dist/index.js health \
  --token "$OPENCLAW_GATEWAY_TOKEN"
🆕 新功能

7. Agent 沙箱功能已可用

現在可以為 Agent 啟用隔離的 Docker 容器執行環境，加強安全性。

# 啟用沙箱
export OPENCLAW_SANDBOX=1
./scripts/docker/setup.sh

# 建構沙箱映像
scripts/sandbox-setup.sh

支援三種模式：off（關閉）、non-main（非主要代理）、all（全部）

📝 補充

8. 建構記憶體需求更明確

官方文件指出：映像建構需要至少 2 GB RAM，在 1 GB 主機上 pnpm install 可能會被 OOM kill（exit 137）。

建議使用 4 GB+ 的機器來建構。

📋 修正後的 Docker 部署流程

Step 1：安裝 Docker 與 Docker Compose（如尚未安裝）

# Ubuntu
sudo apt update
sudo apt install -y docker.io docker-compose-plugin
sudo usermod -aG docker $USER
newgrp docker

# 確認版本
docker --version
docker compose version

Step 2：Clone 並執行（使用新路徑）

# Clone 官方 repo
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# （可選）使用預建映像，省去本地建構
export OPENCLAW_IMAGE="ghcr.io/openclaw/openclaw:latest"

# 執行自動化腳本（新路徑！）
chmod +x ./scripts/docker/setup.sh
./scripts/docker/setup.sh

Step 3：開啟 Control UI

http://127.0.0.1:18789/

貼上 setup 產生的 Gateway Token 即可連線。

Step 4：（建議）設定持久化

# 設定持久化 Volume，確保資料不會因容器重建消失
export OPENCLAW_HOME_VOLUME=openclaw-home
./scripts/docker/setup.sh
⚠️ 重要提醒：如果你的文章是給別人看的教學，強烈建議更新腳本路徑（./docker-setup.sh → ./scripts/docker/setup.sh）和 Node 版本說明。這兩處最容易被引用而踩坑。

📋 OpenClaw Docker 部署 — 完整指令總整理

快速複製使用，建議從頭到尾看過一次再執行

Step 0

環境準備 — 安裝 Docker（如尚未安裝）

# === Ubuntu ===
sudo apt update
sudo apt install -y docker.io docker-compose-plugin
sudo usermod -aG docker $USER
newgrp docker

# 確認版本
docker --version
docker compose version

# === macOS ===
# 下載 Docker Desktop：https://www.docker.com/products/docker-desktop/

# === Windows ===
# 啟用 WSL2 → 安裝 Docker Desktop
Step 1

基本部署（使用預建映像，省去本地建構）

# Clone 官方 repo
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# 使用預建映像（推薦，省時間）
export OPENCLAW_IMAGE="ghcr.io/openclaw/openclaw:latest"

# 執行自動化腳本
chmod +x ./scripts/docker/setup.sh
./scripts/docker/setup.sh
Step 1（選用）

本地建構映像（不用預建，自己 build）

# 不設 OPENCLAW_IMAGE，直接跑腳本即可自動建構
chmod +x ./scripts/docker/setup.sh
./scripts/docker/setup.sh
Step 2

開啟 Control UI

http://127.0.0.1:18789/

在網頁貼上 setup 產生的 Gateway Token 即可連線。

# 若忘記 Token，重新取得
docker compose run --rm openclaw-cli dashboard --no-open
✅ 推薦：完整部署範例

一次搞定持久化 + 預建映像 + 自動化設定

# Clone 並進入目錄
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# 設定環境變數
export OPENCLAW_IMAGE="ghcr.io/openclaw/openclaw:latest"  # 使用預建映像
export OPENCLAW_HOME_VOLUME="openclaw-home"           # 資料持久化
export OPENCLAW_GATEWAY_BIND="lan"               # 可從同網域其他裝置存取

# 執行
chmod +x ./scripts/docker/setup.sh
./scripts/docker/setup.sh

# 完成後開啟瀏覽器
# http://<你的主機IP>:18789/
（選用）

掛載額外主機目錄

export OPENCLAW_EXTRA_MOUNTS="$HOME/my-projects:/home/node/projects:rw"
./scripts/docker/setup.sh

# 以後啟動要加 docker-compose.extra.yml
docker compose \
  -f docker-compose.yml -f docker-compose.extra.yml \
  up -d

⚠️ 疑難排解

常見問題快速查詢

# Q1：權限錯誤 → 把自己加入 docker 群組
sudo usermod -aG docker $USER
newgrp docker

# Q2：忘記 Gateway Token → 重新取得
docker compose run --rm openclaw-cli dashboard --no-open

# Q3：更換 Port（如 18789 被佔用）
export OPENCLAW_GATEWAY_PORT=19000
./scripts/docker/setup.sh

# Q4：容器重啟後資料不見 → 設定持久化 Volume
export OPENCLAW_HOME_VOLUME=openclaw-home
./scripts/docker/setup.sh

# Q5：建構失敗、OOM（記憶體不足）→ 升級機器的 RAM 到 4GB+

# Q6：Unauthorized / pairing required → 重新取 Token 並 approve 裝置
docker compose run --rm openclaw-cli dashboard --no-open
docker compose run --rm openclaw-cli devices list
docker compose run --rm openclaw-cli devices approve <requestId>
