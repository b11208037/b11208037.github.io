💻 第一種安裝方式

OpenClaw + Ollama 本地模型

基本需求

  • Node.js v22+
  • Ollama 最新版
  • 足夠的記憶體/GPU

推薦模型

ollama run gemma4:26b

Mac >48G 記憶體
Windows 有 GPU

📦 Node.js 安裝

# 官方網站下載

https://nodejs.org/zh-tw/download


# Windows 也一樣

node-v24.14.1-x64.msi


# 確認版本

node -v

🦙 Ollama 安裝

# 安裝 Ollama 最新版 (0.20.7)

https://ollama.com/


# 模型下載 (依照設備決定)

ollama run gemma4:26b


# 沒有 GPU？用雲端模型

註冊 ollama.com 帳號免費用雲端額度

🚀 OpenClaw 安裝指令

# 官方網站

https://openclaw.ai/


# 安裝 OpenClaw

npm install -g openclaw@2026.4.10


# Mac 如果無法安裝，打這個：

curl – fsSL https://openclaw.ai/install.sh | bash -s -- --version 2026.4.10

▶️ 啟動 OpenClaw

# 方式一：onboard 精靈

openclaw onboard


# 方式二：launch

ollama launch openclaw

會開啟瀏覽器，用 Google 帳號登入 ollama 取得免費雲端額度

📱 接上 Telegram

💬

讓你的 Agent 透過 Telegram 與你互動

🔧 Telegram Bot 設定

1創建 Bot

打開 Telegram，搜尋 @BotFather，發送 /newbot

2取名字

Bot 名稱（例：Localpinpinpin）
用戶名必須以 bot 結尾（例：Localpinpinpin_bot）

3取得 Token

BotFather 會給你一串 Token

4設定 OpenClaw

把 Token 填入 OpenClaw 設定

🔗 配對 Telegram

# 進入你的 Telegram bot，輸入 /start


# 或直接在終端機執行

openclaw pairing approve telegram 你的配對碼

✨ 就通了！✨
