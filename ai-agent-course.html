📚 一、課程背景

什麼是 AI Agent？

AI Agent（智慧代理）是一種能夠自動執行複雜任務的人工智慧系統。它不只是回答問題，而是能夠：

  • 記憶對話上下文
  • 使用工具和技能（Skills）
  • 透過 API 與外部服務互動
  • 操控電腦執行實際任務

🧠 二、LLM 的演進

一開始的 LLM

一開始，LLM 只是個文字生成器，目的是要文字接龍：

  • ✖ 沒有記憶
  • ✖ 不會使用工具
  • ✖ 只能回答產生的文字

後來加上...

  • 🧠 記憶 Memory - 理解對話上下文
  • 🔧 工具 Tools / Skills - 呼叫外部服務
  • 💓 心跳 Heartbeat - 定時檢查與更新
  • 🖥️ 操控電腦 Computer Use - 操作滑鼠鍵盤

🚀 LLM → Agent 進化

自動執行複雜任務、多步驟推理與行動、與環境互動

🔄 三、Prompt / UI / API 的演進

  • 手動操作：透過官方 UI 輸入 prompt → 等待回覆
  • API 呼叫：程式自動呼叫 API → 即時推論結果
  • Skills / Tools：需要時自動調用外部工具與服務
  • 操控電腦：Agent 可以操作滑鼠、鍵盤、瀏覽器

💻 五、第一種安裝方式

OpenClaw + Ollama 本地模型（免費）

基本需求：

  • Node.js v22+
  • Ollama 最新版
  • 足夠的記憶體/GPU（建議 >48G）

📦 安裝 Node.js

# 官方網站下載
https://nodejs.org/zh-tw/download

# 確認版本
node -v

🦙 安裝 Ollama

# 安裝 Ollama 最新版 (0.20.7)
https://ollama.com/

# 模型下載 (依照設備決定)
ollama run gemma4:26b

# 沒有 GPU？用雲端模型
註冊 ollama.com 帳號免費用雲端額度

🚀 安裝 OpenClaw

# 安裝 OpenClaw
npm install -g openclaw@2026.4.10

# Mac 如果無法安裝，打這個：
curl – fsSL https://openclaw.ai/install.sh | bash -s -- --version 2026.4.10

▶️ 啟動 OpenClaw

# 方式一：onboard 精靈
openclaw onboard

# 方式二：launch
ollama launch openclaw

會開啟瀏覽器，用 Google 帳號登入 ollama 取得免費雲端額度

📱 六、Telegram 串接設定

步驟一：創建 Bot

  • 打開 Telegram，搜尋 @BotFather
  • 發送 /newbot 創建新機器人
  • 取 Bot 名稱（如 Localpinpinpin）
  • 設定用戶名，必須以 bot 結尾（如 Localpinpinpin_bot）
  • 取得 BotFather 給的 Token

步驟二：設定 OpenClaw

把 Token 填入 OpenClaw 的設定中

步驟三：配對

  • 進入你的 Telegram bot，輸入 /start
  • 或在終端機執行：openclaw pairing approve telegram 你的配對碼

✨ 完成！就通了！
