二、方案一：OpenClaw 托管服務（推薦新手）

1 選擇托管平台

OpenClaw 提供官方的托管解決方案，讓您無需管理伺服器。

  • 訪問 OpenClaw 官網或聯繫客服
  • 選擇適合的托管方案
  • 平台會幫您處理伺服器、網路、更新等問題
約 NT$500-2000/月 （視方案而定）

2 申請 LINE 開發者帳號

詳見下方「第四部分：申請 LINE 開發者帳號」

3 連接 LINE 頻道

在 OpenClaw 設定頁面填入 LINE 的 Channel Secret 和 Channel Access Token

# OpenClaw 配置範例
channel: line
channelSecret: "your-channel-secret"
channelAccessToken: "your-access-token"

4 客製化您的 AI 助手

設定 AI 的名字、個性、回答風格等

  • 編輯 SOUL.md 設定 AI 個性
  • 編輯 IDENTITY.md 設定名稱和頭像
  • 設定回覆規則和敏感詞過濾

✅ 優點

  • 不用管理伺服器
  • 系統自動更新
  • 有技術支援
  • 上線時間快速

三、方案二：自架伺服器（進階用戶）

1 準備硬體/雲端資源

選項 A：使用自己的電腦（需開機並運行服務）

選項 B：租用 VPS（虛擬私人伺服器）約 NT$200-1000/月

推薦 VPS 方案：

提供商 價格區間 特點
Railway 約 US$5-20/月 簡單易用
Zeabur 約 US$5-15/月 台灣服務，中文介面
DigitalOcean 約 US$6-48/月 穩定可靠
Vultr 約 US$6-48/月 全球節點

2 安裝 Node.js 環境

在伺服器上安裝 Node.js（建議 v18 以上版本）

# 安裝 Node.js (Ubuntu/Debian)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 驗證版本
node -v
npm -v

3 安裝 OpenClaw

# 全域安裝 OpenClaw
npm install -g openclaw

# 初始化設定
openclaw setup

# 啟動服務
openclaw start

4 設定 LINE Webhook

使用 ngrok 將本地服務暴露給 LINE

# 安裝 ngrok
npm install -g ngrok

# 啟動 ngrok（將 3000 連接埠暴露出去）
ngrok http 3000

# 複製得到的 https URL
# 貼到 LINE Developers Console 的 Webhook URL

5 申請 LINE 開發者帳號

詳見下一章節

6 設定自動啟動

使用 PM2 或 systemd 讓 OpenClaw 在伺服器啟動時自動運行

# 安裝 PM2
npm install -g pm2

# 啟動 OpenClaw
pm2 start openclaw --name "line-assistant"

# 設定開機自動啟動
pm2 startup
pm2 save

四、申請 LINE 開發者帳號

1 創建 LINE Developers 帳號

  • 前往 LINE Developers Console
  • 使用 LINE 帳號登入（或創建新帳號）
  • 點擊「建立 Provider」
  • 輸入您的 Provider 名稱（如：家庭群組）
免費

2 創建 Messaging API 頻道

  • 在 Provider 頁面，點擊「建立頻道」
  • 選擇「Messaging API」
  • 填入頻道設定：
    • 頻道名稱：您的 AI 助手名稱
    • 頻道描述：簡述功能
    • 類別：選擇適合的分類
  • 同意條款並創建
免費

3 取得憑證

在 Messaging API 設定頁面，取得以下資訊：

  • Channel Secret（頻道密鑰）
  • Long-lived access token（長期存取權杖）

⚠️ 重要提醒

這些憑證就像密碼一樣，請勿外流！

4 設定 Webhook

  • 在 Messaging API 設定頁面，找到「Webhook URL」
  • 填入您的服務網址（格式：https://your-domain.com/webhook）
  • 關閉「使用 LINE 官方帳號回應」功能

5 邀請 AI 助手加入群組

  • 在手機 LINE 中，開啟您的 AI 頻道
  • 點擊「加入群組」或分享邀請連結
  • 將 AI 助手加入您的家族群組

六、專家建議

🎯 給綱哥的建議

根據您的需求（家族群組使用），建議：

  • 如果想快速上線：使用 OpenClaw 托管服務，大約 NT$1000/月以内
  • 如果想省錢：使用家中的電腦 + ngrok，完全免費但需要技術維護
  • 如果將來要擴展功能：自架 VPS，彈性最大

⚠️ 建置前注意事項

  • LINE 官方帳號認證：國外電話號碼可能無法通過 LINE 官方帳號的「認證」審核，只能使用「未認證」的官方帳號，功能會有限制（好友人數上限 50 人）
  • 家庭用途：成員不多於 50 人的情況下，未認證帳號應該足夠使用
  • Webhook 穩定性：如果使用 ngrok，免費版的 URL 每次重啟都會改變，需要重新設定

🔧 推薦建置流程（新手適用）

  1. Step 1：申請 LINE 開發者帳號 → 免費

  4. Step 4：客製化 AI 助手的名稱和個性

總時間：約 1-2 小時
